# 📰 Fake News Detection Using NLP

## 📌 Project Overview

This project detects whether a news article is **Fake** or **Real** using **Natural Language Processing (NLP)** and **Machine Learning**. The model is trained on the Fake and Real News Dataset using TF-IDF Vectorization and Logistic Regression.

This project was developed as part of the **CodeAlpha AI/ML Internship**.

---

## 🎯 Objective

The objective of this project is to build a machine learning model that can automatically classify news articles as **Fake** or **Real** based on their textual content.

---

## 🚀 Features

- Load and preprocess news dataset
- Clean and normalize text
- Remove stopwords and perform stemming
- Convert text into numerical vectors using TF-IDF
- Train Logistic Regression model
- Evaluate model performance
- Display Confusion Matrix
- Predict whether custom news is Fake or Real
